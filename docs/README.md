# StudyPilot AI

A student study assistant prototype built with Next.js, React, and TypeScript.

## Features

- Study Planner
- Rule-based Study Coach
- Java practice quiz
- Task progress summary
- Suggested study sessions

## Run locally

Install dependencies:

    npm.cmd install

Start the development server:

    npm.cmd run dev -- --webpack

Open http://localhost:3000.

## Current limitations

The Study Coach uses predefined rules rather than a live AI model.
It is not currently connected to Amazon Alexa.
Tasks use browser localStorage and are not synced between devices.
